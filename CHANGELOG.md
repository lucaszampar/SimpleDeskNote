# Changelog

All notable changes to SimpleDeskNote are documented here.

## [1] — 2026-10-27

First release.

- Sticky notes on the desktop, below windows and above the wallpaper and
  desktop icons, with an option to keep them above all windows.
- Title next to the color dot; the body scrolls when the text grows.
- Live markup: bold, italic, underline, strikethrough, code and headings,
  with the markers hidden.
- Clickable checkboxes (☐/☑) and radio options (○/◉); lists continue on
  Enter.
- Formatting toolbar with hints on every button.
- Five colors, move by dragging the header, resize from the corner.
- Per-monitor positions that survive unplugging and re-plugging monitors.
- Automatic saving to `~/.local/share/simpledesknote/notes.json`.
